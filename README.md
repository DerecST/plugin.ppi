# PickPlayerItem

バニラのスポイト機能を拡張し、他プレイヤーをスポイトしたときに、その相手がメインハンドに持つアイテムを自分のホットバーに寄せるPaperプラグインです。

- リポジトリ: https://github.com/DerecST/plugin.ppi
- 対応: Paper 26.1（`api-version: '26.1'`）
- バージョン: 1.0.0

## 機能

| 視線先 | 挙動 |
|--------|------|
| ブロック | 変更なし（バニラのまま） |
| プレイヤー | 相手のメインハンドのアイテムを基準に、下記ルールで処理 |
| その他のエンティティ | バニラのまま |

### プレイヤーをスポイトしたとき

- 自分のインベントリに同じアイテムがある
    - バニラのスポイトと同様、そのアイテムを選択中のホットバーに持ってくる
- サバイバルで、同じアイテムがインベントリに存在しない場合 
    - 何もしない
- クリエイティブで、インベントリに存在しない 
    - 相手のメインハンドと同種のアイテムを1個付与
- 相手が何も持っていない
    - 何もしない

### その他

- 操作: バニラと同じスポイト
- 権限: 不要（全員利用可）
- 距離: バニラのスポイトに準拠

## 必要環境

- [Paper](https://papermc.io/) 26.1以降

## 導入方法

1. [Releases](https://github.com/DerecST/plugin.ppi/releases) から `PickPlayerItem-1.0.0.jar`を入手する  
2. サーバーの `plugins` フォルダに配置する  
3. ユーザーを再起動する（`/reload` より再起動を推奨）

## 使い方

1. 他プレイヤーに照準を合わせ、スポイト操作を行う
2. 条件を満たす場合、自分のインベントリ内の同種アイテムを手に持つ
